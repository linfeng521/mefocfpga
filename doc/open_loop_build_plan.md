# MeFocFPGA 分步搭建路线

## 第一阶段：Clarke（已实现模块级验证）

采用两相、幅值不变的 Clarke：Ialpha = Ia，Ibeta = (Ia + 2 Ib) / sqrt(3)。
前提为三相电流之和为零；输入是经过零偏校正与归一化的 signed Q1.15。
倒数常数使用 round(32768 / sqrt(3)) = 18919。
加法扩展到 18 位，乘法保留 34 位，算术右移 15 位后饱和至 [-32768, 32767]。
量化采用算术右移截断，不额外四舍五入。

时序：在边沿 N 接收 i_valid 和电流，在边沿 N+1 输出 o_valid 和对应结果。
可连续每拍输入；无有效输出时保持上一次结果；复位清空在途数据。
保留现有 clk/rst_n/i_a/i_b/i_alpha/i_beta 接口，避免破坏顶层连接。
新模块后续使用 i_/o_ 方向命名。

参考比较：
- GithubFOCFPGA 的 clark_tr 使用三相输入、移位加法和不同增益，不直接照搬其数值尺度。
- MeFocFPGAbak 使用 if 输入 / else if 输出，连续输入会阻塞输出，不适合作为流水线模板。
- 原 MeFocFPGA 两相结构可以保留，修正输出饱和和中间乘积表达。

仿真入口：sim/tb_clarke_transform.v。覆盖正负数、极值、饱和边界、连续输入、空拍、随机输入和复位中断。

## 后续顺序

1. 固定控制节拍和电角度累加器，明确一圈角度编码及频率关系。
2. 验证 sin/cos 的尺度、象限与有效信号延迟。
3. 验证反 Park，确保电角度与 Vd/Vq 属于同一次更新。
4. 验证 SVPWM 的电压尺度和占空比限幅。
5. 验证中心对齐 PWM、周期边界同步更新、互补死区和默认关断。
6. 集成独立开环顶层，先完成全链路仿真，再核对硬件接口。
7. 电流采样接 Clarke/Park 作为观测通道，之后再考虑电流闭环。

开环电压主链为：电角度累加器 → sin/cos → 反 Park（给定 Vd/Vq）→ SVPWM → PWM。
Clarke 属于电流观测/反馈链，不是开环电压输出的必经模块。
当前仅完成 Clarke 第一步，不代表整套开环或硬件驱动已经验证。
